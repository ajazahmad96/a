    SCIENCE MODE

    Computer Vision

    A camera frame is a grid of pixel numbers. Computer vision algorithms extract meaning from them.

    Machine Learning

    MediaPipe uses neural networks trained on many labelled hand images to locate a palm and then regress hand points.

    Hand Landmark Detection

    The model outputs 21 3D points per hand: wrist plus four joints on each finger.

    Gesture Recognition

    Our own rules compare landmark distances: a finger is extended if its tip is farther from the wrist than its middle joint. A pinch is thumb-to-index distance relative to hand size, with hysteresis. Gestures must stay stable for a hold time and respect a cooldown to avoid accidents.

    Human-Computer Interaction

    Smoothing, dead zones and calibration trade speed against stability, which is a core HCI problem. Mid-air input has no touch feedback, so we add sound and visual cues.
